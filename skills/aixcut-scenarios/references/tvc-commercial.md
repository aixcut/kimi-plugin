# TVC 品牌广告标准工作流（TVC Commercial）

适用：品牌形象片、产品发布片、TVC 商业广告（标准 15 秒 / 30 秒 / 60 秒，横屏 `16:9` 主版或同步竖屏适配版）。

## 1. 品牌简报与事实边界确认

开工前先确认 5 项核心约束，减少后期结构返工：
- **品牌与产品事实**：品牌中英文标准写法、核心 Slogan、已确认的产品卖点与技术参数；不自行添加未经核实的功效或背书承诺。
- **目标时长与画幅**：明确标准广告时长（15s / 30s / 60s）及主画幅（默认 `16:9` 1920×1080，若需同时交付 `9:16` 竖版则在主版定稿后复制时间线适配）。
- **视觉与情绪基调**：明确影片气质（如科技克制 / 温暖人文 / 动感潮流 / 高端质感），落到可检查的镜头节奏、配色、字体和音乐方向，不只停留在「高级感」等抽象词。
- **素材盘点**：核对已有实拍镜头、品牌 Logo、产品图、配音或配乐，标出缺口镜头清单。

## 2. 分镜脚本与声音情绪骨架先行

1. **先提交分镜表确认**：按时间段列出分镜规划（序号、起止节奏、画面内容与景别、旁白/画面文案、声音情绪、素材来源是实拍还是待生成），获用户确认后再动时间线。
2. **典型叙事弧线**：
   - **15 秒版**：强视觉开场（0–3s）→ 核心产品记忆点/场景（3–11s）→ 品牌 Slogan + Logo 落版（11–15s）。
   - **30 秒版**：情绪/世界观建立（0–6s）→ 冲突或渴望递进（6–13s）→ 产品登场与高光演示（13–24s）→ 价值升华 + 品牌落版（24–30s）。
3. **声音骨架优先**：先确定旁白配音（`aixcut-voice`）和主配乐的情绪起承转合（`aixcut-generation` 报价确认后生成或导入已有配乐），以真实声音和音乐重拍作为镜头落点锚点。

## 3. 缺镜补齐与 AI 生成规范

1. 优先复用品牌实拍镜头；确需补充概念空镜、氛围过渡镜头或定制配乐时，走 `aixcut-generation`（先 `quote` 报价，获用户明确同意后再 `submit`）。
2. 生成提示词遵循 **SLCT 商业结构**（Subject 主体 + Lighting 光影质感 + Camera 景别与运镜 + Technical 色调/画幅一致性），保持全片光线和视觉风格连贯。
3. 严禁让 AI 生成画面篡改产品外观细节，也不得以创意生成画面冒充真实实测。

## 4. 精剪、视觉克制与三层声音设计

1. **镜头与转场**：利用动作顺接、景别递进与音乐节拍组织主轨（`aixcut_primary`）；转场克制统一（`aixcut_transition`），避免廉价花哨特效破坏品牌调性。
2. **字幕与品牌落版**：
   - TVC 字幕保持克制、留白合理、字体统一（`aixcut_caption` / `aixcut_style`），不做电商叫卖式大红大黄花字堆砌。
   - 片尾留足 2–4 秒干净的品牌落版（品牌名、核心 Slogan、Logo），入场/出场动效平稳流畅（`aixcut_motion`）。
3. **三层声音架构**：
   - **旁白/人声**：干净稳定，语速留有呼吸感；
   - **音乐**：开头铺垫、中段蓄力、产品高光处推向高潮、落版干净收尾；人声处适度下潜；
   - **环境音与关键音效**：只在强化质感的关键动作点加入细腻音效，不密集轰炸。

## 5. TVC 审片与交付检查清单

用 `aixcut_review` + 多时点 `aixcut_frontend(action="capture_timeline_frames")` 核验：
- [ ] **品牌规范零失误**：品牌名称、Slogan、产品型号、Logo 在全部字幕与落版中拼写一致。
- [ ] **画面连贯与留白**：各段色调/构图衔接自然，文字不压主体，片尾落版居中完整。
- [ ] **时长精准达标**：成片总时长符合 15s / 30s / 60s 目标预算，无多余黑场或截断尾音。
- [ ] **证据边界如实说明**：未经过真实连续播放与试听的音频混音，明确标注音频待用户试听复核。
- [ ] **工程与成片交付**：默认交付可编辑时间线；用户确认导出时通过 `aixcut-export` 打开导出弹窗，可导出成片视频，也可导出 XML / Aixcut 工程 / 剪映工程供后期精调色或终混。
