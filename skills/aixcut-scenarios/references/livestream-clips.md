# 直播切片标准工作流（Livestream Clips）

适用：把长直播回放拆成多条 15–60 秒、能独立看懂且有传播或带货价值的短视频切片。

## 1. 开工前先对齐目标

在动时间线前，先确认 3 件事（用户已明确则不重复问）：
- **切片类型**：商品卖点讲解 / 产品实操演示 / 主播观点金句 / 福利逼单高光。
- **目标条数与单条时长**：默认单条 15–60 秒；不需要为了覆盖率把整场直播硬切完。
- **投放画幅与平台**：默认 `9:16` 竖屏（抖音 / 视频号 / 小红书）；横屏素材需明确重构图或上下分屏方案。

## 2. 转写扫描与高光筛条（先看全貌再切）

1. 用 `aixcut_read(view="source_lines")` 分页读取完整直播转写，不凭猜测直接切时间点。
2. 按四维信号筛选候选片段：
   - **主题完整度**：围绕单一卖点或观点，具备「背景/痛点 → 讲解/演示 → 结论/行动」的独立语义；
   - **信息与情绪峰值**：核心痛点、价格机制、反差演示、主播语速或语气明显抬升的段落；
   - **可去噪性**：排除长时间等待、喝水、口播卡顿与无意义刷屏互动；
   - **原意保护**：严禁把反问句、前提条件、适用限制或注意事项剪掉，避免断章取义。
3. 先向用户列出「候选切片清单」（序号、主题、对应原片时段、核心看点、发现的过期活动/口误提示），确认要做的条数与优先级后再批量建轴。

## 3. 黄金 3 秒重组与节奏压榨

1. **禁止从头平铺到尾**：将本条最有冲击力的结果、核心卖点或金句前置到 `0–3s` 做开头钩子（仅当该素材有独立看点且不与正文生硬重复时前置，否则从最强自然起句切入）。
2. **清理无效停顿与口癖**：在确认后的语义骨架上，用 `aixcut_speech` 删除 >0.5s 死气口、明显口误、重复卡顿和无关互动，保留自然呼吸和必要强调。
3. **每条切片独立时间线**：用 `aixcut_timeline(action="create")` 或 `aixcut_timeline(action="duplicate")` 为每条切片建立独立时间线并清晰命名（如 `切片01-核心卖点-9x16`），后续所有读写显式绑定对应的 `timeline_id`。

## 4. 竖屏构图、字幕与卖点包装

1. **画幅与构图**：
   - 单主播直播：使用 `aixcut_layout` 做人脸居中裁切，保留自然头顶余量与手势空间；避免过度放大导致画质模糊（超过 1.5 倍需截帧核验清晰度）。
   - 带货/演示直播：可采用上下分屏或主画面 + 商品特写小窗（在 `aixcut_clip` 覆盖轨放置商品细节镜头，确保字幕轨位于覆盖轨之上）。
2. **字幕与关键词花字**：
   - A-roll 语音定稿后再用 `aixcut_caption` 生成并校准同步字幕，重点校对商品名、SKU、数字和价格。
   - 用 `aixcut_text` 在独立文字轨放置开头标题条、核心卖点标签或价格标牌；文字避开顶部状态栏、右侧互动按钮和底部标题区。
3. **音效与配乐**：只在关键转折或卖点出现时补克制的短音效或低音量铺底音乐（`aixcut_audio`），保证主播原声清晰优先。

## 5. 直播切片专项质检清单

交付前结合 `aixcut_review` 与 `aixcut_frontend(action="capture_timeline_frames")` 逐条核查：
- [ ] **独立可理解**：没看过原直播的观众能否在 3 秒内看懂这条在讲什么？
- [ ] **语义未失真**：原话里的否定词、适用条件、注意事项是否完整保留？
- [ ] **时效与合规**：直播时的「今晚秒杀 / 限时赠品 / 当场价格」是否仍有效？是否含广告法极限词？失效或存疑内容必须标出提醒用户确认。
- [ ] **画面与安全区**：人物脸部、产品细节、字幕与标题有无互相遮挡或被平台 UI 遮挡？
- [ ] **声音与导出**：未实际试听的切片如实标明音频待听检；默认交付多条可编辑时间线，用户确认导出后再走 `aixcut-export`。
