# 电商信息流标准工作流（E-Commerce Feed Ads）

适用：面向抖音、视频号、小红书等手机竖屏信息流的高转化带货/投放短片（通常 15–30 秒）。

## 1. 先建「商品事实表」，绝不虚构卖点

开工前先盘点用户提供的商品资料、实拍图片/视频与脚本，明确 4 项事实：
- **单条唯一核心卖点**：一条信息流只打透 1 个核心卖点或解决 1 个明确购买疑问（多卖点应拆成多条矩阵版本，不要塞在一条里）。
- **已确认规格与机制**：价格、规格、优惠条件、适用人群/禁忌以用户确认为准，严禁自行编造功效或优惠。
- **真实证据素材**：优先使用真实产品演示、实拍特写、真实前后对比；只有商品图时围绕真实图片组织说明和局部裁切，**禁止用 AI 生成不存在的产品功能或冒充实测效果**。
- **投放画幅与时长**：默认 `9:16`（1080×1920），黄金时长 15–25 秒（复杂演示不超过 35 秒）。

## 2. 标准四段转化结构（AIDA / 钩子-痛点-实证-CTA）

在 `EditPlan` 中冻结四段镜头分配与时间预算后再写时间线：

| 阶段 | 参考时间 | 剪辑目标 | 画面与声音要求 |
| --- | --- | --- | --- |
| **黄金钩子（Hook）** | `0–3s` | 强行打断划走 | 前 1.5 秒内至少 1 次景别切换或视觉重锤（痛点反差 / 暴力测试结果 / 核心利益大字）；禁止慢节奏空镜头开场 |
| **痛点共鸣（Pain）** | `3–9s` | 快速对号入座 | 具象展示用户崩溃/困扰瞬间，用局部聚焦、红圈/放大或紧凑快切抓住共鸣 |
| **卖点实证（Proof）** | `9–20s` | 眼见为实的信任 | 用产品特写、使用操作、同帧前后对比或 3 条核心卖点逐个弹出支撑主张；拒绝空洞形容词 |
| **转化收口（CTA）** | 尾帧 `2–3s` | 清晰行动指令 | 给出明确下一步（点击卡片 / 查看规格 / 领取优惠），尾帧停留够读完 |

## 3. 声画节奏与高可读视觉包装

1. **先声音后画面**：若使用新配音，先按 `aixcut-voice` 定稿并生成真实语音，再依据实际句词时间落镜头和字幕；若使用实拍口播，先定 A-roll 语音骨架再铺演示 B-roll。
2. **节奏密度**：平均每 1.5–2 秒保持一个有效视听变化（切镜、景别推近、卖点花字、演示动作），避免连续超过 3 秒无信息推进的静止画面。
3. **高对比可读视觉配方（复用 Aixcut 实测规范）**：
   - **价格 / 利益标牌**：亮背景或花哨背景上，标题用高对比字色加外描边，价格用醒目红底白字底板，辅助说明用深色半透明底板，三层视觉层级清晰。
   - **卖点逐条出现**：多条卖点错开入场（约 0.8–1.0 秒错峰），避开画面原有文字与产品主体，配合简洁入场动效（`aixcut_motion`）。
   - **前后对比**：仅对真实可比素材使用并排/双窗对比（`aixcut_layout`）并加明确「使用前 / 使用后」标签，不同拍摄条件不得冒充公平实测。
   - **轨道层级**：覆盖演示视频或小窗放入独立视频轨，字幕轨与卖点文字轨保持在视频覆盖轨之上（`aixcut_track`）。
4. **声音平衡**：人声解说清晰第一；BGM 选择明快有律动的风格并在人声段压低音量（`aixcut_audio`）；在转折和重点词处点缀短音效，不每一刀都堆音效。

## 4. 电商信息流专项质检清单

用 `aixcut_review` + 手机竖屏尺寸的 `aixcut_frontend(action="capture_timeline_frames")` 核验：
- [ ] **前 3 秒钩子到位**：第 1 秒是否已出现核心主题、产品或视觉反差？
- [ ] **卖点有画面支撑**：每句核心卖点是否都有对应产品画面或已确认资料支撑？
- [ ] **小屏可读与安全区**：单行字幕简短（建议不超过 12 字）、重点词高亮；所有文字和价格牌避开抖音/小红书底部和右侧 UI 遮挡区，不遮挡产品细节。
- [ ] **广告合规**：逐字检查字幕、花字和配音，排除「全网第一」「国家级」「最好」「100% 根治」等违禁极限词，核对价格和活动期限无误。
- [ ] **交付边界**：默认交付可编辑时间线；用户确认导出后再走 `aixcut-export`（可导出成片视频，也可在编辑器导出弹窗导出 XML / Aixcut 工程 / 剪映工程供投放团队二次微调）。
